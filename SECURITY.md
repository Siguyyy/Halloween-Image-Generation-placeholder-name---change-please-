# Security

Haunt Generator is intended for trusted local networks. The server is designed for a home or party LAN and does not provide user accounts, authentication, or authorization.

Do not expose port 8080 directly to the public internet. Treat uploaded media and generated files as untrusted input, keep the host patched, and stop the server when it is no longer needed.

Please report security issues privately to the repository owner rather than opening a public issue with exploit details.
